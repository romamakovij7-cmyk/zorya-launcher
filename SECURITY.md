# Security

## Reporting a vulnerability

Please **do not publish a vulnerability in public Issues or Discussions** — until it is fixed, that puts players at risk.

Report it privately on GitHub: open the repository's **Security** tab → **Report a vulnerability**. Only the repository owner sees the report.

Please include:

- launcher version (for example from `Zorya-Launcher-Setup-<version>.exe`);
- what is wrong and why it is dangerous;
- steps to reproduce, if possible;
- a suggested fix if you have one (optional).

## What counts as a vulnerability

For example: arbitrary code execution through the launcher, bypassing update signature verification, leaking tokens or account data, reading/writing files outside the launcher folders, or bypassing server-side restrictions.

## What we promise

We will acknowledge the report and keep you informed about the fix. With your consent, we will credit you in the release notes.

## Supported versions

Fixes are released for the latest launcher version only. The launcher updates itself.
